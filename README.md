# RenoCAD

Browser-based 2D CAD drafting app — an AutoCAD-style drafting experience on the web.

- Command line with AutoCAD aliases, ortho/snap/polar drafting aids
- Layers, dimension styles, layouts/paperspace, templates
- DXF, SVG, PNG, and JSON save/export
- Feet–inches architectural units standard

Open `index.html` or visit the GitHub Pages deployment.
