2D Drafting — quick reference

Feet–inches (architectural) is the default: readouts, typed input and dimensions all speak ft-in like 10'6" or 1'6 1/2". Metric stays under Units. The ribbon mirrors AutoCAD 2026 (Home / Insert / Annotate / Parametric / View / Manage / Output / Add-ins / Collaborate / Featured Apps / Express Tools tabs, with Draw · Modify · Annotation · Layers · Block · Properties · Groups · Utilities · Clipboard · View panels on Home, a red A application menu, the drawing's file tab underneath, and the ⌃ Minimize button cycling the ribbon like AutoCAD), the UI ships in the dark theme (◐ in the top bar flips it light), and the command window at the bottom keeps a scrolling history with autocomplete: start typing and matching commands drop down (↑/↓ + Enter picks, ↑/↓ on an empty line recalls recent commands, F2 opens the full history, Ctrl+9 hides the window). While any command runs, type exact values in the floating box (Tab switches fields, Enter confirms) or in the command line — Esc always cancels back to Select, and right-click pops the current command's options (idle right-click repeats the last command). Aliases follow AutoCAD exactly (C Circle · REC Rectangle · EL Ellipse · E Erase · R Redraw · D Dimstyle · DI Distance · CO Copy · X Explode): just start typing anywhere and the keys land in the command line — Enter runs exactly what you typed, nothing is guessed.

L / PL / SPL / REC / C / A / EL / POL / DO / XLLine (keeps going segment after segment; U undoes one, C closes) · Polyline · Spline (smooth curve through the points; C closes) · Rectangle (right-click for Chamfer/Fillet corners) · Circle · Arc (3-point, right-click for Center) · Ellipse · Polygon · Donut (inside/outside diameters, then a ring per click) · Construction line (infinite guide through two points)
M · CO · RO · SC · MI · ST · O · TR · EX · F · CHA · AR · X · J · BR · DIV · ME · LEN · AL · H · MA · GMove · Copy · Rotate · Scale · Mirror (asks Erase source? [Yes/No] <N>) · Stretch (crossing window first: geometry inside the window moves, the rest stays) · Offset (copies toward the side you click) · Trim (Quick mode: everything cuts, Shift+click extends, type T for cutting edges) · Extend (Shift+click trims) · Fillet · Chamfer · Array · Explode · Join · Break · Divide (equal segments) · Measure (points every typed length) · Lengthen (DElta/Total, then click near an end) · Align (2 source→destination point pairs, optional scale) · Hatch · Match properties · Group (G binds the selection so it picks and moves as one; UNGROUP releases it)
E · R · U · OOPS · LI · DI · AA · IDErase the selection · Redraw · Undo (Ctrl+Z too) · OOPS restores the last erased objects · LIST reports the selection in the command window · DIstance / ARea / ID measure and report
DIM · DLI · DAL · DRA · DDI · DAN · DAR · DOR · DCE · DBA · DCO · DEDSmart dimension (circle→diameter, arc→radius, line→linear) · Linear · Aligned · Radius · Diameter · Angular · Arc length · Ordinate (datum = origin) · Center mark · Baseline (each line steps out by the style's baseline spacing) · Continue (chains on the same line) · Dimedit. Dimensions picked from geometry are associative: move or stretch the source and the dimension follows; erasing the source leaves it fixed in place
D · DS · LA · PR · UNDimension styles · Drafting settings (object-snap modes, tracking, dynamic input, lineweight display) · Layers panel · Properties panel · Units (View tab)
F7 Grid · F9 Snap · F8 Ortho · F10 Polar · F3 OSnap · F11 OTrack · F12 Dyn · F2 HistoryOrtho locks horizontal/vertical (Shift temporarily inverts it); Polar snaps to the chosen increment plus your custom angles (View tab → Polar settings) with a dotted tracking path and tooltip; object snap finds endpoints, midpoints, centres, quadrants, intersections (nearest optional in DS); OTrack tracks horizontally/vertically from hovered snap points; the status-bar pills at bottom-right toggle the same aids
Typed entryLine: length + angle · Rect: W,H · Circle: radius or D120 for diameter · Move/Copy: type a distance to travel along the polar-tracked direction (direct distance entry), @ΔX,ΔY for a relative vector, or dist<angle · Offset: distance, two points, or M for Multiple
Window / CrossingNo holding the button: click one corner, move, click the opposite corner (press-and-drag still works too). Left→right (blue) selects fully-enclosed objects only; right→left (green dashed) selects anything touched. Works idle and at any "Select objects:" step (MOVE, COPY…); Esc cancels a half-built window
Enter / SpaceSpace works exactly like Enter (AutoCAD-style): it runs a typed command, confirms typed values and selections, finishes polylines, and repeats the last command when idle. It only inserts a real space while typing actual text
Command windowDrag the grip strip above the command line to show more or fewer history lines (double-click resets); the size is saved with the drawing. Zoom buttons and Fit glide smoothly; the object under the cursor highlights before you pick it
Dim stylesAnnotate tab → Dimension styles…: arrowheads (closed / tick / dot / open), text height & placement, ft-in / fractional / decimal / metric precision, extension-line offset & overshoot, global fit scale, baseline spacing, symmetric / deviation / limits tolerances, zero suppression. Per-dimension overrides live in Properties (label, text height, style, break association). Changing a style restyles its dimensions
LayoutsTabs under the canvas: Model + sheets. Pick a paper size, draw viewports, set print scales like 1/4″=1′-0″, lock them, fill the title block, then Export → Layout sheet (PDF/PNG). Viewport borders never print
TemplatesFile → New from template: Arch D / Arch C / Letter / A1 / A3 presets, plus Save setup as template for your own
Ctrl+S · SAVE / QSAVESave the drawing as an AutoCAD-compatible .dxf (opens natively in AutoCAD; File → Save as .json keeps the editable app copy)
Ctrl+Z / Ctrl+Y · Ctrl+D · Del · arrowsUndo / redo · duplicate · delete · nudge (Shift = ×10). Scroll zooms, middle-drag or the Pan tool pans, Shift+F fits

Save your work: File → Save (or Ctrl+S, or the SAVE command) writes an AutoCAD-compatible .dxf in one click — AutoCAD opens .dxf natively with geometry, layers and dimensions intact (true .dwg is Autodesk's proprietary format, which no browser app can author). File → Save as .json keeps a fully editable copy for this app (dim styles, layouts and templates too); reopen it with File → Open. Drawings live in this page only — save before closing the tab.

Compatibility & scope

Reference version: AutoCAD 2026, 2D drafting scope. Explicitly deferred rather than approximated: the parametric constraint solver (the Parametric tab carries the dimensional commands only), the BLOCK / INSERT / ATTDEF block engine (GROUP/UNGROUP covers object sets), associative hatches, and external references (XREF). Dimensions are associative when picked from geometry. A control is only shown when the command behind it works.

Dimension styles

Styles control how every dimension looks. New dimensions use the current style; editing a style updates all dimensions that use it.

Polar tracking

While a command runs, the cursor snaps to tracked angles measured from the last point: every increment around the circle, plus any custom angles you add. When an angle engages, a dotted tracking path runs through the last point, past the cursor, and a tooltip shows the snapped angle and distance. F10 turns polar tracking on or off.
